# Colony RPG Wiki -- Projektstart

Dieses Projekt ist das Grundgerüst für ein öffentliches
deutschsprachiges Spieler-Wiki und eine daraus erzeugte PDF-Ausgabe.

## Geplante Technik

-   Zensical für die Online-Dokumentation
-   GitHub Pages für die öffentliche Veröffentlichung
-   Markdown als gemeinsame Inhaltsquelle
-   PDF-Export aus derselben Inhaltsbasis

## Vor Veröffentlichung

1.  Vorhandene Kapiteltexte in die jeweiligen Dateien übernehmen.
2.  Aussagen gegen die aktuelle Modliste, Konfigurationen und Datapacks
    prüfen.
3.  Quellen und externe Links für jeden Artikel ergänzen.
4.  Navigation und interne Links testen.
5.  PDF-Ausgabe erzeugen und visuell prüfen.
6.  Erst danach öffentlich bereitstellen.

**Wichtig:** Dieses Grundgerüst ist noch keine veröffentlichte Website.
Es enthält Platzhalter und Redaktionshinweise.
