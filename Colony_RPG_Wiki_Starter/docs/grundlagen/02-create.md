# Create – Technik und Automatisierung

Create erweitert Minecraft um ein technisches Bausystem. Statt Maschinen ausschließlich über Menüs zu bedienen, werden viele Anlagen aus sichtbaren, beweglichen Bauteilen zusammengesetzt. Dadurch entstehen Maschinen und Produktionsabläufe direkt in der Spielwelt.

Auf Colony RPG ist **Create 6.0.10 für Minecraft 1.21.1 mit NeoForge** Teil der Mod-Auswahl.

## Wie funktioniert Create?

Ein zentrales Element von Create ist die mechanische Bewegung. Bauteile können Drehbewegungen erzeugen, weiterleiten oder verändern. Aus einzelnen Komponenten lassen sich dadurch größere technische Anlagen bauen.

Typische Bestandteile sind:

- **Antriebe:** Sie erzeugen die Bewegung, mit der eine Anlage betrieben wird.
- **Wellen und Zahnräder:** Sie übertragen und verändern Drehbewegungen.
- **Maschinen:** Verschiedene Arbeitsblöcke nutzen die mechanische Bewegung, um Aufgaben auszuführen.
- **Transport und Verarbeitung:** Gegenstände und Materialien können innerhalb einer Anlage bewegt und weiterverarbeitet werden.
- **Bewegliche Konstruktionen:** Mehrere Bauteile lassen sich zu größeren beweglichen Vorrichtungen verbinden.

Viele dieser Systeme können auf unterschiedliche Arten aufgebaut werden. Es gibt daher nicht nur eine einzige richtige Bauweise.

## Lernen direkt im Spiel

Create besitzt mit **Ponder** eine visuelle Anleitung im Spiel. Damit lassen sich viele Bauteile und ihre Funktionsweise anhand kleiner Demonstrationen kennenlernen.

Für Rezepte und Verarbeitungsschritte ist außerdem ein Rezeptanzeiger hilfreich. Die normale Minecraft-Rezeptübersicht zeigt nicht alle Create-Rezepte vollständig an.

## Create und MineColonies

Auf Colony RPG ist zusätzlich eine Erweiterung installiert, die Create mit MineColonies verbindet. Sie verknüpft Materialanforderungen der Kolonie mit dem Logistiknetzwerk von Create.

Die Erweiterung kann offene Lieferanforderungen aus MineColonies auslesen und als Materialbedarf an ein eingerichtetes Create-Logistiknetzwerk weitergeben. Dadurch können vorhandene Materialien und automatisierte Transportwege bei der Versorgung einer Kolonie helfen.

Die Verbindung ersetzt nicht das MineColonies-Bausystem: Die Kolonie stellt weiterhin ihre Anforderungen, während Create beim Bereitstellen und Weiterleiten der benötigten Gegenstände unterstützen kann.

## Create auf Colony RPG

Create bietet auf dem Server einen eigenen technischen Spielbereich. Du kannst Anlagen zur Verarbeitung von Materialien bauen, Transportwege gestalten und Automatisierung mit dem Aufbau deiner Kolonie verbinden.

Welche konkreten Maschinen, Rezepte und Abläufe sich daraus ergeben, hängt von den installierten Create-Erweiterungen und den jeweiligen Rezepten ab. Servereigene Handelsregeln und Shop-Funktionen werden im Kapitel [Währung und Shops](../systeme/07-waehrung-und-shops.md) behandelt.
